# Submission evidence

Complete one Markdown file per lab. Automated grading checks the first three sections
for meaningful content and awards one point per completed section. Your instructor
reviews the final explanation section for up to three additional points.

You may paste shortened terminal output when the complete output is very large, but
do not remove fields that support your conclusion.

Never include private keys, wallet seeds, authentication cookies, tokens, or evidence
from a real-value mainnet wallet.

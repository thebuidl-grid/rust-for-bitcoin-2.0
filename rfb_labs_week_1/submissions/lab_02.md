## Explanation

### Bitcoin core can manage multiple independent wallets on a single node for example in this lab I have both a "miner" and a "receiver" wallet
### loaded on the same regtest node. This is imply that each wallet RPC method has to be node by the node which wallet it should be applied to.

### On the other hand rpcwallet=<name> tells bitcoin-cli which loaded wallet the command should operate against.
### Practically this works by changing the RPC endpoint the request is sent to : instead of hitting the node default endpoint
